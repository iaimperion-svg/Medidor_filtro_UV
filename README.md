# Medidor_filtro_UV

Proyecto de medición del nivel de radiación ultravioleta (UV) en tiempo real con Arduino e inteligencia artificial.

## Estado inicial

El proyecto está en preparación. Quedan por definir el hardware, el sensor UV, el papel de la inteligencia artificial y los requisitos de medición.

Las instrucciones de instalación y ejecución se incorporarán cuando exista una primera implementación.

## Colaboración

- Registrar las tareas y los errores en las incidencias de GitHub.
- Trabajar cada cambio en una rama y proponer su integración mediante una pull request.
- Mantener este documento actualizado con las instrucciones necesarias para trabajar en el proyecto.
